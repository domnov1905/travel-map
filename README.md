# Travel Map

Persoenliche interaktive Weltkarte fuer GitHub Pages.

## Veroeffentlichen
1. `index.html`, `style.css` und `app.js` in das Repository hochladen.
2. GitHub: Settings > Pages.
3. Source: Deploy from a branch.
4. Branch: `main`, Ordner: `/ (root)`, dann Save.

Hinweis: Version 1 speichert Markierungen mit `localStorage` nur im jeweiligen Browser. Die Kartendaten werden beim Laden ueber jsDelivr bezogen.
